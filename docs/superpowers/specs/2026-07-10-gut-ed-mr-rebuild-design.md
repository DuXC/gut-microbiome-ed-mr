# 肠道微生物组与勃起功能障碍 MR 升级重建设计

## 1. 项目定位

本项目不是对旧 MiBioGen 文稿做语言润色，而是以旧稿提供的临床问题和写作素材为基础，重新完成一项可复现、可审计、具备当前新颖性的两样本 Mendelian randomization（MR）研究。

项目优先目标是形成一篇独立投稿的原创研究论文。脑功能 rs-fMRI—ED 项目作为第二个独立子项目，仅在本项目完成首轮 go/no-go 评估后启动，避免两个分析工作包相互污染。

## 2. 已批准的决策

- 用户对现有稿件、数据、代码和作者安排拥有完整处置权，并作为最终决策人。
- 原始归档目录保持只读；所有下载、清洗、分析、图表和文稿均在新工作目录中生成。
- 不沿用旧稿的阳性结论；所有结论以新版分析输出为准。
- 不以名义显著 `P < 0.05` 作为主要发现标准。
- 若没有信号通过预设门槛，项目以透明止损报告结束，不制造阳性结果。
- `01_protocol/analysis_decisions.md` 是分析运行决策的规范性来源；README、配置和规则引擎必须实现该文件的规则，不得弱化。

## 3. 研究问题与核心论证

### 3.1 研究问题

采用最新高分辨率 shotgun metagenomic GWAS 和更新的 ED GWAS，评估遗传预测的肠道微生物特征是否与 ED 风险存在可重复的因果关联，并判断这些关联是否独立于主要代谢和心血管危险因素。

### 3.2 一句话论证模板

在肠道微生物组与 ED 的关系中，本研究使用高分辨率微生物 GWAS、独立 ED 结局和严格的多重检验/共定位框架，识别可重复的候选因果微生物特征，并限定结论为遗传工具支持的因果证据。

### 3.3 结论边界

- MR 结果不等同于临床干预效果。
- 菌种丰度的遗传预测效应不直接等同于益生菌、抗生素或粪菌移植的治疗效应。
- 未通过多重校正或独立验证的结果仅列为探索性发现。
- 共定位失败时，不将关联表述为同一因果变异驱动。

## 4. 数据设计

### 4.1 微生物暴露数据

主要暴露使用 2026 年 shotgun metagenomic GWAS 的完整汇总统计：

- GWAS Catalog：`GCST90670368–GCST90671939`
- 发现样本：四个瑞典人群队列，合计约 16,017 人
- 外部复制：HUNT，约 12,652 人
- 表型层级：物种、高阶分类单元、功能模块和多样性指标

如公开文件允许区分发现与复制结果，则保留为独立数据层；不把发现和复制混成同一验证步骤。

### 4.2 ED 结局数据

结局按以下优先级组织：

1. 与微生物暴露队列无明显样本重叠的欧洲 ancestry ED GWAS，作为主要发现结局。
2. 2025 年百万级欧洲 ED meta-GWAS，作为高功效验证结局。
3. 非洲 ancestry 及 cross-ancestry ED GWAS，作为迁移性分析，不与欧洲结果直接合并为单一主要结论。
4. FinnGen 独立版本用于重复验证或敏感性分析。

若某个公开 meta-GWAS 包含与暴露相同的参与者来源，必须记录潜在样本重叠，并使用独立结局替代或进行重叠敏感性分析。

### 4.3 MVMR 协变量

仅对通过主要筛选的微生物特征开展多变量 MR，候选协变量限定为：

- BMI/肥胖
- 2 型糖尿病
- 冠心病或动脉粥样硬化性心血管疾病

协变量的纳入必须有明确的因果图解释；不进行无边界的批量 MVMR。

### 4.4 基因组版本与 ancestry

- 每个数据集记录 genome build、效应等位基因、其他等位基因、频率、样本量和 ancestry。
- build 不一致时进行可审计的 liftOver，并保留转换前后坐标及失败记录。
- LD clumping 使用与分析 ancestry 匹配的参考面板。
- 欧洲、非洲和 cross-ancestry 分析分别报告，不使用欧洲 LD 面板处理非洲 ancestry 工具变量。

## 5. 分析流程

### 5.1 数据摄取与冻结

每个下载文件保存：来源 URL、下载日期、版本/访问号、文件大小、SHA-256、许可说明和原始文件名。原始文件进入 `03_data/raw/` 后只读冻结；清洗结果写入 `03_data/processed/`。未来摄取流程必须拒绝 basename 以 `._` 开头的文件。

### 5.2 工具变量选择

主要分析：

- `P < 5×10⁻⁸`
- ancestry 匹配的 LD clumping
- 默认 `r² < 0.001`、窗口 10,000 kb
- F-statistic > 10
- 删除无法可靠协调的回文 SNP

若某个微生物表型没有足够的 genome-wide significant 工具变量，可进行 `P < 1×10⁻⁵` 的探索性分析，但必须同时满足：

- 明确标为 exploratory；
- 通过独立暴露或结局数据复制；
- 使用弱工具稳健方法；
- 不与主要分析的证据等级混写。

### 5.3 主要 MR

- 单 SNP：Wald ratio
- 多 SNP 主要方法：随机效应 IVW
- 稳健方法：weighted median、MR-Egger、MR-RAPS
- 异常值/多效性：MR-PRESSO（工具数允许时）

报告 beta/OR、95% CI、P 值、工具数、F-statistic、方向和单位。

### 5.4 多重检验

- 在查看 MR 关联 P 值之前，仅依据预先规定的数据源、QC 和工具变量标准冻结分析资格。
- 正向微生物→ED 主要检验和反向 ED→微生物检验为两个独立、预先指定的 BH-FDR 家族，各自控制在 5%，并记录各自的分母 `N_forward` 和 `N_reverse`。
- 严格的全局 Bonferroni 阈值为 `0.05 / (N_forward + N_reverse)`，覆盖两个方向的全部合格检验。
- 物种、高阶分类单元、功能模块、多样性指标或其他分层只用于展示，不得减少任一方向的分母。
- 反向 ED→微生物作为方向性/敏感性评估的独立冻结家族，不使用正向独立复制门槛，永不授予 `primary` 或 `strict` 标签。可估计且合格的反向行标为 `exploratory`，不合格或不可估计的反向行标为 `insufficient`；两者均记录 `analysis_role = reverse_sensitivity`。

### 5.5 稳健性与方向性

对通过 FDR 或进入预设复制流程的结果执行：

- Cochran Q
- MR-Egger intercept
- MR-PRESSO global/outlier test
- leave-one-out
- single-SNP forest/funnel/scatter
- Steiger directionality
- reverse MR
- 必要时 PhenoScanner 或 GWAS Catalog confounder lookup

### 5.6 复制规则

一个候选关联只有在以下门槛全部满足时才视为已复制并可进入主文：

1. 发现分析在正向微生物→ED 主要家族中达到 BH `q < 0.05`；
2. 验证使用样本重叠分类恰为 `none_known` 的独立结局或暴露数据集；已知或可能重叠的验证只作敏感性分析；
3. 验证 beta 与发现 beta 同号，双侧 `P < 0.05`，且 95% CI 在同一方向排除无效值；
4. 发现分析中至少一个预先指定的稳健估计量——weighted median 或可估计时的 MR-RAPS——与主要估计同号，不要求该稳健估计量本身显著；
5. 当 Steiger 可计算时，发现或验证数据均无 `P < 0.05` 支持的方向逆转；无法计算时必须报告，不得默认解释为支持；
6. 两个数据集均无严重水平多效性。严重水平多效性定义为 MR-Egger intercept `P < 0.05`，或 MR-PRESSO global `P < 0.05` 且异常值未解决、校正后估计变号或校正后估计无法获得。无法估计的检验必须明确报告，不得视为通过证据。

缺少任一门槛的候选均不视为已复制，不进入主文，并在补充材料中标为探索性。

### 5.7 共定位

对主文候选信号开展局部共定位。优先使用含完整区域汇总统计的方法，报告 PP0–PP4 或等效指标。若仅有单个工具 SNP 或区域数据不完整，不宣称共定位支持。

### 5.8 MVMR

仅对复制后的候选特征运行。先检查条件 F-statistic 和工具变量共线性；弱工具或严重共线时停止该模型。MVMR 结果作为机制/独立性补强，不覆盖主要单变量 MR。

## 6. Go/No-Go 门槛

### Go：进入正式写稿

至少一个 Primary 信号满足全部复制门槛。

### Conditional Go：短文或探索性报告

没有 Primary 已复制信号，但至少一个不依赖 `P < 1×10⁻⁵` 工具变量的 genome-wide-instrument 候选在发现分析中名义 `P < 0.05`，在独立验证中 `P < 0.05` 且 95% CI 在同一方向排除无效值，并通过其他所有稳健估计、方向性、多效性和重叠门槛。此时仅允许探索性方法学/复制型短报告，不使用 confirmed-causal 语言。

### No-Go：止损

- 既无 GO 模式，也无上述 Conditional-Go 模式；或
- 阳性完全依赖 `P < 1×10⁻⁵` 的弱工具；或
- 信号被方向性、多效性或共定位检查否定；或
- 新数据与已发表文献相比没有可辨认的方法学或数据增量。

No-Go 时输出完整分析报告和可复现代码，不强行生成投稿稿件。

## 8. 产出物

### 8.1 故障与异常处理

- 下载中断：使用可续传下载；完成后必须通过文件大小和 SHA-256 校验，失败文件不进入分析。
- 访问受限：记录数据集、访问条件和阻断日期；优先寻找同等质量的公开独立数据，不以网页摘要或不完整 top-hit 表替代完整 GWAS。
- genome build 或等位基因无法统一：将对应 SNP 写入排除日志；不静默丢弃或猜测方向。
- ancestry 匹配参考面板缺失：暂停该 ancestry 分析，不借用不匹配的 LD 面板。
- 工具变量不足：降级为探索性单 SNP/Wald 分析或终止该表型，不降低质量门槛制造多 SNP 结果。
- 包版本或随机过程导致输出不一致：固定软件版本和随机种子，保留 session 信息；不一致未解释前不更新主结果。
- 数据源后续更新：冻结当前版本完成本轮分析，新版本另开分析批次，不在同一结果集中混用。

### 8.2 Go 情况

- 冻结版 protocol 与分析决策日志
- 数据来源/许可/校验清单
- 可重复运行的 R 脚本和环境锁定文件
- 主结果表、敏感性表、共定位表、MVMR 表
- 主图和补充图
- 英文主文 DOCX
- 补充材料 DOCX/XLSX
- STROBE-MR checklist
- cover letter
- 投稿前一致性与版式 QC 报告

### 8.3 No-Go 情况

- 完整 go/no-go 报告
- 全部可复现代码和结果表
- 失败原因、可复用数据资产和后续研究建议

## 9. 质量保证

- 原始文件哈希与下载记录一致。
- 每一步分析均可从冻结数据重跑。
- 关键统计量由脚本自动生成，不手工抄录到正文。
- 正文、表格和图中的样本量、效应值、CI、P 值和方向自动核对。
- 论文不得保留旧稿中的菌群名称、作者、样本量或结果，除非新分析重新支持。
- DOCX 交付前执行完整渲染与逐页视觉检查。
- 最终结论通过 claim–evidence map 审计。

## 10. 第二子项目边界

脑功能 rs-fMRI—ED 项目不与本项目共用结果目录或代码入口。本项目完成首轮 go/no-go 后，为脑功能项目另写独立设计规格，重点处理：

- UK Biobank rs-fMRI 与 ED 结局的样本重叠；
- `P < 5×10⁻⁸` 工具变量；
- 191 表型双向多重校正；
- 对 2026 年已发表同题研究的独立复现和增量价值。

## 11. 成功定义

项目成功不等同于获得阳性结果。成功定义为：在不复用旧稿错误结论的前提下，完成一套可审计、可复现、对当前文献真正有增量的分析，并据此作出可信的投稿或止损决定。
